    `tools/check_licences.py` (stdlib only): `evaluate_expression(expr, allowed) -> bool` parses an SPDX expression (identifiers, `AND`, `OR`, `WITH`, parentheses; `AND` binds tighter than `OR`; `X WITH Y` evaluates as `X`; identifiers compared case-insensitively; `LicenseRef-*` never allowed). `licence_of(dist, config) -> (expression_or_None, source)` reads, in order: a reviewed override in the config, the `License-Expression` metadata field (PEP 639), the `License` field when it is a recognised SPDX id or alias, then `License ::` classifiers mapped through the config's `classifier_map` (several classifiers combine with OR). `check_distributions(dists, config) -> list[Violation]` returns one violation per distribution whose licence is unknown or not allowed. `main(argv) -> int` loads `tools/licence-allowlist.json`, checks `importlib.metadata.distributions()`, prints violations sorted by name, and exits 0 (clean) or 1.

    `tools/licence-allowlist.json`: `schema_version` 1; `allowed`: MIT, MIT-0, MIT-CMU, BSD-2-Clause, BSD-3-Clause, Apache-2.0, PSF-2.0, ISC; `aliases` for common free-text values (for example "Apache 2.0", "Apache License 2.0", "BSD", "PSF", "MIT License"); `classifier_map` (MIT License → MIT, BSD License → BSD-3-Clause, Apache Software License → Apache-2.0, Python Software Foundation License → PSF-2.0, ISC License (ISCL) → ISC, MIT No Attribution License (MIT-0) → MIT-0); `overrides` with one reviewed entry for `pypdfium2` (licence `BSD-3-Clause AND Apache-2.0`, reason: its License field is free text listing BSD-3-Clause, Apache-2.0 and dependency licences, reviewed_on 2026-10-17); `note`: "MPL-2.0 and any copyleft licence need owner review before they are added." Run the script on the dev environment; for any further distribution whose metadata is free text but permissive, add a reviewed override with its reason. A genuinely non-permissive licence is reported to the owner, not overridden.
