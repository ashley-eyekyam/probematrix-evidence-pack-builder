## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PyPI → user's private environment | End users download and run third-party packages |
| setup → user's file system | Setup creates and removes folders under the per-user data folder |
| host sandbox → setup | Codex or Claude Code may block network or writes outside the project |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-24 | Tampering | core install in run_setup | high | mitigate | pip >= 26.1 then `--uploaded-prior-to P14D`; exception pins only from the reviewed shipped file (D-18) |
| T-01-25 | Elevation of privilege | run_setup | high | mitigate | Installs only into the private venv with its own interpreter; never the system Python, never sudo; elevated commands (apt) are printed for the user, not run |
| T-01-26 | Tampering | stale rebuild | medium | mitigate | Removes only `data_root()/envs/<this version>` after checking its parent; sibling versions untouched (tested) |
| T-01-27 | Denial of service | hung pip or venv | low | mitigate | Timeouts on every subprocess (300 s venv, 900 s pip); failure leaves no marker so the next run rebuilds |
| T-01-SC | Tampering | pip installs of plugin/requirements.txt | high | mitigate | Same package list the owner approved at the 01-01 blocking-human legitimacy checkpoint (precondition on Task 1); no new package is added here |
</threat_model>
