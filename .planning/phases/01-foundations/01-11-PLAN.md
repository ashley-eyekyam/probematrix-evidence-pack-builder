| case folder → git / sync services | Raw-text state could leave the machine through git or a sync client |
| workspace files → shareable artefacts | INDEX.md and trackable state may be shared with other people |

| T-01-30 | Tampering | init over an existing INDEX.md | low | mitigate | Refuse with BAD_ARGUMENT instead of overwriting a file the plugin did not create |
| T-01-SC | Tampering | package installs | low | accept | This plan installs no packages |
</threat_model>
